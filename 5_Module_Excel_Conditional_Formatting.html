T32 · Conditional Formatting

📌 What is it?

Conditional Formatting automatically changes a cell's appearance (color, icon, bar) based on its value — so patterns, outliers, and important numbers jump out visually, without you manually coloring anything.

🛠️ How to highlight cells by a rule (e.g., Sales > 100000)

  1. Select the range of cells (e.g., the Sales Amount column).
  2. Go to Home tab → Conditional Formatting → Highlight Cells Rules → Greater Than...
  3. Type the value to compare against (e.g., 100000).
  4. Choose a formatting style from the dropdown (e.g., "Green Fill with Dark Green Text").
  5. Click OK.

🛠️ How to add Data Bars, Color Scales, or Icon Sets

  1. Select the range of numbers.
  2. Go to Home tab → Conditional Formatting.
  3. Choose Data Bars (in-cell bar length shows relative size), Color Scales (gradient from low to high), or Icon Sets (arrows/traffic lights based on value).
  4. Pick a style — it applies instantly.

🛠️ How to create a Custom Rule (using a formula)

  1. Select the range.
  2. Home tab → Conditional Formatting → New Rule...
  3. Choose "Use a formula to determine which cells to format".
  4. Type a formula that returns TRUE/FALSE, e.g. =$E2>100000
  5. Click Format..., choose a fill/font style, click OK, then OK again.

🛠️ How to remove Conditional Formatting

  1. Select the affected range (or the whole sheet).
  2. Home tab → Conditional Formatting → Clear Rules → Clear Rules from Selected Cells (or Entire Sheet).

🌍 Real-world example

In a sales sheet, applying Data Bars to the "Sales Amount" column instantly shows which orders are biggest — longer bar = higher sale — without reading every number.

⚠️ Common mistakes

Mistake: Selecting only one cell instead of the full column/range before applying the rule — the formatting then only affects that single cell.

T33 · Data Validation (Drop-down Lists)

📌 What is it?

Data Validation restricts what can be typed into a cell — commonly used to create a drop-down list, so users can only pick from a fixed set of options instead of typing freely (which prevents typos and inconsistent entries).

🛠️ How to create a Drop-down List

  1. Select the cell(s) where the dropdown should appear (e.g., the "Order Status" column).
  2. Go to Data tab → Data Validation.
  3. In the "Allow" dropdown, choose List.
  4. In the "Source" box, type your options separated by commas, e.g. Pending,Completed,Cancelled
  5. Click OK.
  6. Click any cell in that range — a small dropdown arrow appears; click it to pick a value.

🛠️ How to create a Drop-down from a cell range (better for long lists)

  1. Type your list of options somewhere in the sheet (e.g., in cells H1:H3).
  2. Select the target cell(s) for the dropdown.
  3. Data tab → Data Validation → Allow: List.
  4. In Source, click the range selector icon and select H1:H3 instead of typing values directly.
  5. Click OK.

⏰ When to use this

Use Data Validation whenever a column should only ever contain a fixed set of values — statuses, departments, yes/no fields, grades — to keep data clean and consistent for later sorting, filtering, and formulas like SUMIF/COUNTIF.

⚠️ Common mistakes

Mistake: Typing a comma-separated list with extra spaces (e.g., Pending, Completed) — the space becomes part of the option and can cause mismatches in formulas later. Keep it clean: Pending,Completed.

T34 · Remove Duplicates & Text to Columns

📌 What is it?

Remove Duplicates deletes repeated rows automatically. Text to Columns splits one column's text into multiple columns based on a delimiter (like a comma, space, or dash).

🛠️ How to Remove Duplicates

  1. Click any cell inside your data range.
  2. Go to Data tab → Remove Duplicates.
  3. A dialog shows all your columns with checkboxes — keep all ticked if a duplicate should only count when every column matches.
  4. Click OK.
  5. Excel shows a summary: how many duplicate rows were removed and how many unique rows remain.

🛠️ How to use Text to Columns

  1. Select the column you want to split (e.g., a column with "Laptop-North" style entries).
  2. Important: make sure there's an empty column to the right, or existing data there will be overwritten.
  3. Go to Data tab → Text to Columns.
  4. Choose Delimited → click Next.
  5. Tick the delimiter that separates your data (e.g., tick "Other" and type - for a dash, or tick "Comma" / "Space" as needed) → click Next.
  6. Preview the split columns at the bottom → click Finish.

🌍 Real-world example

A "Product_Region" column with values like Laptop-North can be split using Text to Columns with delimiter - into two clean columns: "Product" (Laptop) and "Region" (North) — making it possible to Sort/Filter/SUMIF by Region alone.

⚠️ Common mistakes

Mistake: Running Text to Columns without an empty column ready on the right — it will silently overwrite whatever data was already there.
Mistake: Using Remove Duplicates with only some columns ticked when you meant to check the whole row — this can delete rows that only match partially, not truly identical duplicates.

T35 · Charts (Column, Bar, Pie, Line)

📌 What is it?

Charts turn rows of numbers into visual pictures, making trends and comparisons much easier to understand at a glance.

🧩 Which chart type to use

Chart TypeBest for
Column ChartComparing values across categories (vertical bars), e.g. sales by product
Bar ChartSame as Column but horizontal — good when category names are long
Pie ChartShowing proportion/percentage of a whole, e.g. market share by product
Line ChartShowing trends over time, e.g. monthly sales growth

🛠️ How to create a Chart

  1. Select the data you want to chart, including headers (e.g., Product names + Sales Amount).
  2. Go to Insert tab → Charts group.
  3. Click the chart type you want (Column, Bar, Pie, or Line) and pick a sub-style from the dropdown.
  4. The chart appears on the sheet — drag its corner to resize, or drag the chart itself to reposition.

🛠️ How to edit a Chart

  1. Click the chart to select it — this reveals the Chart Design and Format tabs on the Ribbon.
  2. Use Chart Design → Add Chart Element to add/edit a Title, Data Labels, Axis Titles, or Legend.
  3. Use Chart Design → Change Chart Type if you want to switch, e.g., from Column to Line.
  4. Right-click any data series → Format Data Series to change colors.

🌍 Real-world example

A Pie Chart of "Sales Amount by Product" instantly shows which product contributes the biggest slice of total revenue — much faster to grasp than scanning a table of numbers.

⚠️ Common mistakes

Mistake: Selecting the wrong data range (e.g., including an ID column as if it were numeric data) — this creates a confusing or meaningless chart. Only select category labels + the actual numeric values you want to compare.

T36 · Printing, Page Layout & Headers/Footers

📌 What is it?

This covers preparing a worksheet so it prints correctly on paper — setting margins, orientation, and adding headers/footers (like page numbers or a report title) that appear on every printed page.

🛠️ How to set Page Orientation & Margins

  1. Go to Page Layout tab.
  2. Click Orientation → choose Portrait or Landscape.
  3. Click Margins → choose Normal, Wide, Narrow, or Custom Margins.

🛠️ How to set the Print Area

  1. Select the exact range of cells you want to print.
  2. Page Layout tab → Print Area → Set Print Area.
  3. Only this selected range will print, even if there's more data on the sheet.

🛠️ How to add Headers/Footers

  1. Go to Insert tab → Header & Footer (switches to Page Layout view).
  2. Click into the top area to type a Header (e.g., a report title), or the bottom area for a Footer.
  3. Use the Header & Footer Elements options that appear (like Page Number, Date, File Name) to insert dynamic fields.
  4. Click anywhere outside the header/footer box when done.

🛠️ How to Preview and Print

  1. Press Ctrl + P to open Print Preview.
  2. Check how the pages will look — adjust scaling under "Settings" if content is getting cut off (e.g., choose "Fit Sheet on One Page").
  3. Click Print when it looks correct.

⏰ When to use this

Always preview before printing large reports — checking Print Area and page fit prevents wasted paper and split tables across multiple pages.

⚠️ Common mistakes

Mistake: Not setting a Print Area on a sheet with extra stray data far below/right of the main table — Excel may print many blank/extra pages. Always set the Print Area explicitly.

T37 · Practical Exercise — Sales Report

📌 Goal

Apply everything from T32–T36 on a real sales dataset: Conditional Formatting, Data Validation, Remove Duplicates, Text to Columns, Charts, and Print setup.

Dataset provided: Sales_Report_Dataset.xlsx — 25 orders with a combined "Product_Region" column (e.g., "Laptop-North"), Salesperson, Quantity, Sales Amount, and a blank "Order Status" column. Contains 3 intentional exact-duplicate rows for Remove Duplicates practice.

🛠️ Step-by-step exercise instructions

  1. Open Sales_Report_Dataset.xlsx.
  2. Remove Duplicates first: Click inside the data → Data tab → Remove Duplicates → OK. Confirm 3 duplicate rows are removed (25 rows should become 22).
  3. Text to Columns: Insert two new empty columns after "Order ID" (right-click column B → Insert, twice), label them "Product" and "Region". Select the "Product_Region" column → Data tab → Text to Columns → Delimited → Other: - → Finish. Confirm Product and Region are now separate.
  4. Data Validation: Select the "Order Status" column → Data tab → Data Validation → List → Source: Pending,Completed,Cancelled → OK. Fill in a status for each order using the dropdown.
  5. Conditional Formatting: Select the "Sales Amount" column → Home tab → Conditional Formatting → Data Bars → pick any color style.
  6. Conditional Formatting (custom rule): Add a second rule highlighting Sales Amount > 100000 in green fill, using Highlight Cells Rules → Greater Than.
  7. Chart 1 (Column): Select Product and Sales Amount columns (use Ctrl to select both non-adjacent columns) → Insert tab → Column Chart. Add a chart title: "Sales by Product".
  8. Chart 2 (Pie): Select Region and Sales Amount → Insert tab → Pie Chart. Add a chart title: "Sales Share by Region".
  9. Page Layout: Go to Page Layout tab → set Orientation to Landscape → Print Area → Set Print Area over the data table.
  10. Header/Footer: Insert tab → Header & Footer → type "Sales Report – Module 5" as the header, insert Page Number in the footer.
  11. Preview with Ctrl + P to confirm it looks clean, then save the file with Ctrl + S.

⚠️ Common mistakes to avoid during the exercise

Mistake: Running Text to Columns before inserting the empty destination columns — this overwrites the "Salesperson" column that originally sits right next to "Product_Region".
Mistake: Forgetting to select header cells when creating a chart — without headers, the chart legend/labels show as "Series1" instead of meaningful names.

🌍 Real-world example

This mirrors how a real sales manager cleans and reports monthly data: dedupe raw exports, split combined fields, standardize status entries with a dropdown, highlight top performers with conditional formatting, and present the summary in charts and a printable report.

T38 · Test 5

📌 Purpose

Test 5 checks understanding of T32–T37: Conditional Formatting, Data Validation, Remove Duplicates, Text to Columns, Charts, and Print/Page Layout setup.

📝 Likely test areas

  • Steps to apply a Conditional Formatting rule (both a preset rule and a custom formula rule).
  • Steps to create a dropdown list using Data Validation, and why it's useful.
  • Difference between Remove Duplicates behavior when all columns vs only some columns are ticked.
  • Correct delimiter choice and column-order caution for Text to Columns.
  • Choosing the right chart type for a given scenario (proportion vs trend vs comparison).
  • Steps to set a Print Area and add a Header/Footer.

🛠️ How to prepare

  1. Redo the T37 sales report exercise from scratch without instructions.
  2. Practice explaining, in one line each, when you'd use a Column vs Pie vs Line chart.
  3. Re-check the Text to Columns steps carefully, especially the "insert empty columns first" precaution.

⚠️ Common mistakes seen in tests

Mistake: Mixing up "Delimited" vs "Fixed Width" in Text to Columns — for data separated by a symbol (comma, dash, space), always choose Delimited.
Mistake: Choosing a Pie Chart for data that changes over time — Pie Charts show proportion at a single point, not trends; a Line Chart is correct for trends.

⚡ Quick Revision — Module 5

  • Conditional Formatting (Home tab): auto-styles cells based on value — preset rules, Data Bars/Color Scales/Icon Sets, or custom formula rules.
  • Data Validation (Data tab → Data Validation → List): creates dropdown lists to keep entries consistent.
  • Remove Duplicates (Data tab): deletes rows that fully match across ticked columns.
  • Text to Columns (Data tab): splits one column into many by a delimiter — always keep an empty column ready on the right first.
  • Charts (Insert tab): Column/Bar = compare categories, Pie = show proportion, Line = show trend over time.
  • Print setup (Page Layout tab): set Orientation, Margins, and Print Area before printing; use Insert → Header & Footer for titles/page numbers; preview with Ctrl+P.
