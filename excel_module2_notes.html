T9 · Copy, Cut, Paste & Paste Special

📌 What is it?

Copy duplicates data while keeping the original in place. Cut moves data, removing it from the original location. Paste places that data elsewhere. Paste Special lets you paste only specific parts (like values only, or formatting only) instead of everything.

🛠️ How to Copy & Paste

  1. Select the cell(s) you want to copy.
  2. Press Ctrl + C (or right-click → Copy).
  3. Click the destination cell.
  4. Press Ctrl + V (or right-click → Paste).

🛠️ How to Cut & Paste (move data)

  1. Select the cell(s).
  2. Press Ctrl + X (or right-click → Cut).
  3. Click the destination cell.
  4. Press Ctrl + V. The data disappears from the original location.

🛠️ How to use Paste Special

  1. Copy the cell(s) first (Ctrl + C).
  2. Right-click the destination cell → Paste Special... (or press Ctrl + Alt + V).
  3. Choose an option:
    • Values — pastes only the result, not the formula.
    • Formats — pastes only formatting (colors, borders), not the data.
    • Formulas — pastes only the formula.
    • Transpose — flips rows into columns (or columns into rows).
  4. Click OK.

⏰ When to use Paste Special

Use Paste Values when you copy a formula result and don't want the formula (and its cell references) to come along. Use Transpose when your data was entered in rows but you need it in columns, or vice versa.

⚠️ Common mistakes

Mistake: Copying a cell with a formula and pasting it elsewhere — the formula's cell references shift automatically, which can give wrong results if not checked. Use Paste Values if you just want the number.

T10 · AutoFill & Fill Handle

📌 What is it?

The Fill Handle is the small square dot at the bottom-right corner of a selected cell. Dragging it lets Excel automatically continue a pattern — numbers, dates, days, or repeated text — into adjacent cells. This is called AutoFill.

🛠️ How to use the Fill Handle

  1. Click the cell containing the starting value (e.g., type EMP001 in a cell).
  2. Hover your mouse over the small square at the bottom-right of the cell until the cursor becomes a thin black +.
  3. Click and drag down (or across) as far as you need.
  4. Release the mouse — Excel fills in the pattern automatically (EMP002, EMP003, EMP004...).

🛠️ How to AutoFill a series from two starting values

  1. Type the first value in one cell (e.g., 2) and the next value in the cell below (e.g., 4).
  2. Select both cells.
  3. Drag the Fill Handle down — Excel detects the pattern (+2 each time) and continues it: 6, 8, 10...

📋 What AutoFill can detect automatically

Starting ValueAutoFill Result
MondayTuesday, Wednesday, Thursday...
JanFeb, Mar, Apr...
Qtr 1Qtr 2, Qtr 3, Qtr 4...
2023-01-012023-01-02, 2023-01-03...
EMP001EMP002, EMP003...

⏰ When to use this

Use AutoFill whenever you need a repeating pattern — Employee IDs, Serial numbers, dates, or month names — instead of typing each one manually.

⚠️ Common mistakes

Mistake: Dragging the Fill Handle on plain text expecting numbers to increase — a single cell with just "5" copied via Fill Handle repeats "5" everywhere unless you hold Ctrl while dragging (which forces it to increment).

T11 · Flash Fill

📌 What is it?

Flash Fill is a smart Excel feature that detects a pattern from an example you type and automatically fills the rest of the column to match — useful for combining, splitting, or reformatting text without writing formulas.

🛠️ How to use Flash Fill

  1. Make sure you have a source column next to an empty column (e.g., First Name and Last Name columns, with an empty "Full Name" column beside them).
  2. In the first empty cell, manually type the result you want as an example (e.g., type Rohit Sharma combining First + Last Name).
  3. Click the next cell down and start typing — Excel will show a greyed-out preview of the rest of the column following the same pattern.
  4. Press Enter to accept, and the entire column fills automatically.
  5. Alternative: after typing 1-2 examples, go to Data tab → Flash Fill (or press Ctrl + E).

🌍 Real-world examples of Flash Fill

Combining: First Name "Rohit" + Last Name "Sharma" → Flash Fill produces "Rohit Sharma" in the Full Name column.

Extracting: From an email like "rohit.sharma@company.com", Flash Fill can extract just "rohit.sharma" or just the domain "company.com" once you show it one example.

Reformatting: Converting "SHARMA, ROHIT" into "Rohit Sharma" (proper case, reordered).

⏰ When to use this

Use Flash Fill for one-time quick text transformations. For something that needs to update automatically when source data changes, a formula (like CONCATENATE or TEXT functions, covered in a later module) is better since Flash Fill results are static text, not a live formula.

⚠️ Common mistakes

Mistake: Expecting Flash Fill to update automatically if the source data changes later — it won't, because it pastes fixed text, not a formula. You'd need to redo Flash Fill.

T12 · Find, Replace & Go To

📌 What is it?

Find searches for specific text/values in a sheet. Replace finds and swaps text with something else automatically. Go To jumps directly to a specific cell, range, or type of cell (like all blanks).

🛠️ How to use Find

  1. Press Ctrl + F.
  2. Type the text/number you're searching for in the box.
  3. Click Find Next to jump to each matching cell one at a time, or Find All to list every match.

🛠️ How to use Find & Replace

  1. Press Ctrl + H.
  2. In "Find what", type the text to search for (e.g., Banglore).
  3. In "Replace with", type the correct text (e.g., Bangalore).
  4. Click Replace to fix one at a time, or Replace All to fix every occurrence in the sheet at once.

🛠️ How to use Go To

  1. Press Ctrl + G (or F5).
  2. Type a cell address (e.g., H25) and press Enter to jump there.
  3. For advanced use, click Special... in the Go To box to select all Blanks, all Formulas, all Constants, etc. in one click.

⏰ When to use this

Use Find & Replace to quickly fix a spelling mistake repeated across many rows (like a misspelled city name) instead of correcting each cell manually.

⚠️ Common mistakes

Mistake: Using "Replace All" without checking matches first — it can accidentally replace text inside unrelated words. For example, replacing "IT" with "Information Technology" could also change "CredIT" if not careful. Use "Match entire cell contents" option in the Find & Replace dialog to avoid this.

T13 · Sort & Filter

📌 What is it?

Sort rearranges rows in a chosen order (A-Z, Z-A, smallest-largest, oldest-newest). Filter temporarily hides rows that don't match a condition you set, without deleting any data.

🛠️ How to Sort data

  1. Click any cell inside your data range.
  2. Go to Data tab → Sort (or for a quick single-column sort, use the A→Z / Z→A buttons).
  3. In the Sort dialog, choose the column to sort by (e.g., "Salary").
  4. Choose order: Smallest to Largest, or Largest to Smallest.
  5. Click Add Level to sort by a second column too (e.g., sort by Department, then by Salary within each department).
  6. Click OK.

🛠️ How to apply Filter

  1. Click any cell inside your data range.
  2. Go to Data tab → Filter (or press Ctrl + Shift + L).
  3. Small dropdown arrows appear on each header cell.
  4. Click the dropdown arrow on a column (e.g., "Department") → untick "Select All" → tick only the values you want (e.g., only "IT") → click OK.
  5. Only matching rows will now be visible; others are hidden (not deleted).
  6. To remove the filter, click the same dropdown → "Clear Filter", or click Data → Filter again to turn it off completely.

⏰ When to use Sort vs Filter

Use Sort when you want to reorder all your data (e.g., see employees from highest to lowest salary). Use Filter when you only want to temporarily view a subset (e.g., only Sales department employees) while keeping the rest of the data safe underneath.

⚠️ Common mistakes

Mistake: Selecting only one column before sorting — this can shuffle that column's data out of sync with the rest of the row. Always click inside the full data range (or select the entire range) so Excel sorts whole rows together.

T14 · Freeze Panes, Split & Hide/Unhide

📌 What is it?

Freeze Panes locks certain rows/columns in place so they stay visible while scrolling. Split divides the window into separate scrollable sections. Hide/Unhide temporarily conceals rows or columns without deleting them.

🛠️ How to Freeze the top row (headers)

  1. Go to View tab → Freeze Panes → Freeze Top Row.
  2. Now when you scroll down, the header row stays fixed at the top.

🛠️ How to Freeze a specific row/column combination

  1. Click the cell just below and to the right of what you want frozen (e.g., click B2 to freeze row 1 and column A together).
  2. Go to View tab → Freeze Panes → Freeze Panes.
  3. Everything above and to the left of your click stays visible while scrolling.

🛠️ How to use Split

  1. Click a cell where you want the split to happen.
  2. Go to View tab → Split.
  3. The window divides into panes that can be scrolled independently — useful for comparing distant parts of a large sheet.
  4. Click Split again to remove it.

🛠️ How to Hide/Unhide rows or columns

  1. Select the row number(s) or column letter(s) you want to hide.
  2. Right-click → Hide.
  3. To unhide: select the rows/columns just before and after the hidden ones → right-click → Unhide.

⏰ When to use these

Use Freeze Panes on large datasets so column headers stay visible while you scroll through hundreds of rows. Use Hide when a column has sensitive or temporarily unnecessary data (like internal notes) that you don't want visible but still need to keep.

⚠️ Common mistakes

Mistake: Forgetting where a column was hidden and thinking data is lost — hidden columns still exist. Select the surrounding columns and use Unhide, or select all (Ctrl+A) then Unhide to reveal everything.

T15 · Practical Exercise — Employee Database

📌 Goal

Apply everything from T9–T14 on a real dataset: AutoFill, Flash Fill, Find & Replace, Sort, Filter, and Freeze Panes.

Dataset provided: Employee_Database_Dataset.xlsx — 20 employees with Emp ID (only first 2 filled), First Name, Last Name, Full Name (empty), Department, City (contains a repeated misspelling "Banglore"), Date of Joining, Salary, and Email ID (empty). Built specifically so each blank/error gives you something to practice.

🛠️ Step-by-step exercise instructions

  1. Open Employee_Database_Dataset.xlsx.
  2. AutoFill practice: Select cells A2:A3 (EMP001, EMP002), then drag the Fill Handle down to A21 to auto-generate EMP003 through EMP020.
  3. Flash Fill practice: In the "Full Name" column (D), type Rohit Sharma in D2 (combining First + Last Name), press Enter, click D3 and press Ctrl + E to Flash Fill the rest.
  4. Flash Fill practice #2: In the "Email ID" column (I), type rohit.sharma@company.com in I2 (lowercase first.last@company.com pattern), then use Flash Fill (Ctrl + E) to generate the rest automatically.
  5. Find & Replace practice: Press Ctrl + H, find "Banglore" and replace all with "Bangalore".
  6. Sort practice: Select the data range → Data tab → Sort → sort by "Department" (A-Z), then add a second level sorting by "Salary" (Largest to Smallest).
  7. Filter practice: Apply Filter (Ctrl + Shift + L) → filter the Department column to show only "IT" employees. Note how many appear, then clear the filter.
  8. Freeze Panes practice: View tab → Freeze Panes → Freeze Top Row, then scroll down to confirm headers stay visible.
  9. Copy/Paste Special practice: Copy the "Salary" column, paste it into a blank column using Paste Special → Values Only, to see the difference from a normal paste.
  10. Save the file using Ctrl + S.

⚠️ Common mistakes to avoid during the exercise

Mistake: Forgetting to press Enter after typing the Flash Fill example before pressing Ctrl+E on the next cell — Flash Fill needs at least one confirmed example to detect the pattern.
Mistake: Sorting only the Department column without including the whole row — always select/click within the full data range so related row data doesn't get separated.

🌍 Real-world example

HR teams use exactly this kind of workflow: AutoFill for Employee IDs, Flash Fill to quickly generate company email addresses from names, Find & Replace to fix inconsistent city/department spellings, and Filter to instantly view "all employees in a department" during audits or reports.

⚡ Quick Revision — Module 2

  • Copy (Ctrl+C) keeps the original; Cut (Ctrl+X) removes it from source. Paste Special (Ctrl+Alt+V) lets you paste only Values, Formats, Formulas, or Transpose.
  • Fill Handle = small square at bottom-right of a cell; drag it to AutoFill patterns like numbers, dates, days, or IDs.
  • Flash Fill (Ctrl+E) learns from one typed example to auto-complete a column — great for combining/splitting text, but result is static (not a live formula).
  • Find (Ctrl+F) locates text; Replace (Ctrl+H) swaps it everywhere; Go To (Ctrl+G) jumps to a specific cell or selects special cell types.
  • Sort reorders all rows by a column's values. Filter (Ctrl+Shift+L) temporarily hides non-matching rows without deleting anything.
  • Freeze Panes keeps headers visible while scrolling. Split creates independently scrollable sections. Hide/Unhide conceals rows/columns without deleting them.
  • Always select/click within the full data range before Sort/Filter so rows stay correctly matched.
