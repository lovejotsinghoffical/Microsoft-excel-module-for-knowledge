T1 · Introduction to Excel, Workbook, Worksheet, Ribbon, Interface

📌 What is it?

Microsoft Excel is a spreadsheet program — software used to store, organize, calculate, and analyze data in the form of rows and columns.

🧩 Key terms

TermMeaning
WorkbookThe entire Excel file (extension .xlsx). One workbook can contain many worksheets.
Worksheet (Sheet)A single page/tab inside the workbook, made of rows and columns. You can see sheet tabs at the bottom.
RibbonThe toolbar strip at the top with tabs like Home, Insert, Page Layout, Formulas, Data, Review, View.
CellA single box where a row and column meet — where you type data.

🖥️ Excel Interface — main parts

  1. Title Bar — top-most bar showing the file name.
  2. Ribbon — tabs (Home, Insert, Formulas, etc.) with grouped commands/buttons.
  3. Formula Bar — shows the content/formula of the currently selected cell.
  4. Name Box — small box left of Formula Bar showing the active cell's address (e.g., A1).
  5. Worksheet area — the grid of rows and columns where you enter data.
  6. Sheet Tabs — bottom tabs to switch between worksheets; use the "+" icon to add a new sheet.
  7. Status Bar — bottom strip showing quick info like Sum/Average of selected cells, zoom controls.

🛠️ How to open Excel and create a new workbook

  1. Click the Start menu → type "Excel" → open Microsoft Excel.
  2. On the Excel start screen, click Blank Workbook.
  3. A new workbook opens with one sheet, usually named Sheet1.

⚠️ Common mistakes

Mistake: Confusing "Workbook" and "Worksheet" — remember, Workbook = the whole file (like a notebook), Worksheet = one page inside it.

🌍 Real-world example

A school might keep one Workbook named "Student Records.xlsx" with separate Worksheets for each class — "Class10A", "Class10B", "Class10C" — all in the same file.

T2 · Rows, Columns, Cells, Cell Address & Navigation

📌 What is it?

An Excel sheet is a grid made of Rows (horizontal, numbered 1, 2, 3...) and Columns (vertical, lettered A, B, C...). The box where a row and column cross is called a Cell.

⚙️ How Cell Addresses work

Every cell has a unique address written as ColumnLetter + RowNumber. Example: B3 means Column B, Row 3.

Example: The cell in Column D, Row 5 is called D5. A group of cells like B2 to D6 is written as a range: B2:D6.

🛠️ How to navigate a worksheet

  1. Click any cell with the mouse to select it directly.
  2. Type a cell address into the Name Box (top-left) and press Enter to jump there instantly.
  3. Use arrow keys (↑ ↓ ← →) to move one cell at a time.
  4. Press Ctrl + Home to jump to cell A1.
  5. Press Ctrl + End to jump to the last used cell in the sheet.
  6. Press Ctrl + → or Ctrl + ↓ to jump to the edge of a data block.

⏰ When to use this

Use Name Box navigation or Ctrl+End when working with large sheets (hundreds/thousands of rows) — much faster than scrolling.

⚠️ Common mistakes

Mistake: Beginners often say "row A" or "column 3" — remember, rows are always numbers, columns are always letters.

T3 · Data Entry, Editing, Save/Open Workbook

📌 What is it?

This covers how to type data into cells, correct mistakes, and save your work so it isn't lost.

🛠️ How to enter data

  1. Click on a cell to select it.
  2. Type the value (text or number).
  3. Press Enter to confirm and move down, or Tab to move right.

🛠️ How to edit existing data

  1. Double-click the cell to edit inside it directly, OR select the cell and press F2.
  2. Make your changes, then press Enter.
  3. To clear a cell's content only, select it and press Delete.

🛠️ How to save a workbook

  1. Press Ctrl + S, or go to File → Save.
  2. First time saving: choose a location, type a file name, keep format as .xlsx, click Save.
  3. To save a copy with a new name, use File → Save As.

🛠️ How to open an existing workbook

  1. Open Excel → click File → Open.
  2. Browse to the file location and double-click the file, OR just double-click the file directly from File Explorer.

⚠️ Common mistakes

Mistake: Forgetting to save regularly. Always press Ctrl + S every few minutes to avoid losing work if Excel crashes.

T4 · Formatting Cells (Font, Alignment, Borders, Colors, Wrap Text)

📌 What is it?

Formatting changes how data looks without changing the actual value — making sheets easier to read and more professional.

🛠️ How to format Font (bold, size, color)

  1. Select the cell(s).
  2. Go to the Home tab → Font group.
  3. Click B for Bold, I for Italic, U for Underline.
  4. Use the Font Size dropdown to increase/decrease text size.
  5. Click the Font Color (A with red underline) dropdown to change text color.

🛠️ How to set Alignment

  1. Select the cell(s).
  2. In Home tab → Alignment group, click Left / Center / Right align icons for horizontal alignment.
  3. Use Top / Middle / Bottom align icons for vertical alignment.

🛠️ How to add Borders

  1. Select the cell range.
  2. In Home tab → Font group, click the small dropdown arrow next to the Borders icon (looks like a grid).
  3. Choose an option, e.g., All Borders for a full grid.

🛠️ How to apply Fill Color (cell background)

  1. Select the cell(s).
  2. Home tab → click the dropdown next to the paint-bucket icon (Fill Color).
  3. Pick a color.

🛠️ How to Wrap Text

  1. Select cell(s) where text is overflowing or getting cut off.
  2. Home tab → Alignment group → click Wrap Text.
  3. The row height will auto-adjust so all text is visible on multiple lines within the cell.

⚠️ Common mistakes

Mistake: Confusing Font Color with Fill Color — Font Color changes the text color; Fill Color changes the cell background color.

🌍 Real-world example

In a report, headers are usually made Bold, Center-aligned, with a colored Fill, and All Borders — so they stand out clearly from the data below.

T5 · Row Height, Column Width, Insert/Delete Rows & Columns

📌 What is it?

Adjusting how much space rows/columns take up, and adding or removing rows/columns as your data changes.

🛠️ How to resize Column Width

  1. Manual: Hover mouse on the line between two column letters until you see a ↔ cursor, then click-drag.
  2. Exact value: Right-click the column letter → Column Width → type a number → OK.
  3. Auto-fit: Double-click the border line between two columns to auto-fit width to the longest content.

🛠️ How to resize Row Height

  1. Manual: Hover on the line between two row numbers until you see a ↕ cursor, then click-drag.
  2. Exact value: Right-click the row number → Row Height → type a number → OK.

🛠️ How to Insert a Row or Column

  1. Right-click the row number (or column letter) next to where you want the new one.
  2. Click Insert. A new blank row appears above, or a new blank column appears to the left.

🛠️ How to Delete a Row or Column

  1. Right-click the row number (or column letter) you want to remove.
  2. Click Delete.

⚠️ Common mistakes

Mistake: Pressing Delete key only clears cell content, but the empty row/column still exists. To fully remove a row/column, use right-click → Delete, not the Delete key.

T6 · Number Formatting (Currency, Date, Time, Percentage, Decimal)

📌 What is it?

Number formatting controls how a number is displayed — as currency, date, percentage, etc. — without changing its actual underlying value.

🛠️ How to apply Number Formats (Quick way)

  1. Select the cell(s) with numbers.
  2. Go to Home tab → Number group.
  3. Use the dropdown (says "General" by default) to pick: Number, Currency, Date, Time, Percentage, etc.
  4. Or click the quick icons: $ for Currency, % for Percentage, , for comma-style thousands separator.

🛠️ How to apply Custom / Detailed Formats

  1. Select the cell(s).
  2. Right-click → Format Cells (or press Ctrl + 1).
  3. Go to the Number tab in the dialog box.
  4. Choose a category (Currency, Date, Percentage, etc.) and set decimal places or symbol as needed.
  5. Click OK.

📋 Common formats reference

FormatExample InputDisplayed As
Currency85000₹85,000.00
Date2026-01-0505-Jan-2026
Percentage0.9292%
Decimal (2 places)7878.00
Time13:301:30 PM

⚠️ Common mistakes

Mistake: Typing "92%" directly sometimes gets stored differently than expected. Safer approach: type 0.92 then apply Percentage format, or type 92% directly and let Excel auto-convert it.

T7 · Practical Exercise — Student Information Sheet

📌 Goal

Apply everything learned in T1–T6 on a real dataset: entering data, resizing, formatting cells, and number formatting.

Dataset provided: Student_Information_Dataset.xlsx — contains 15 students with Roll No, Name, Class, Date of Birth, Gender, Contact Number, Email ID, Fee Amount, Fee Paid Date, Attendance (%), and Marks Obtained. The data is deliberately left unformatted so you can practice formatting it yourself.

🛠️ Step-by-step exercise instructions

  1. Open Student_Information_Dataset.xlsx.
  2. Header row: Select row 1 → make it Bold, Center-aligned, apply a Fill Color (e.g., light green), and add All Borders.
  3. Column width: Auto-fit all columns so no text is cut off (double-click column border lines, or select all columns → Home → Format → AutoFit Column Width).
  4. Freeze header row (optional): View tab → Freeze Panes → Freeze Top Row, so headers stay visible while scrolling.
  5. Fee Amount column: Apply Currency format (₹ symbol, 0 decimals).
  6. Date of Birth & Fee Paid Date columns: Apply Date format as DD-MMM-YYYY (e.g., 05-Jan-2026).
  7. Attendance (%) column: Apply Percentage format if values are stored as decimals, or simply confirm the % symbol displays correctly.
  8. Borders: Select the entire data range (A1 to K16) → apply All Borders for a clean grid look.
  9. Insert a new row at the top for a sheet title, e.g. type "Student Information Sheet – BTech 2026" in cell A1, then merge & center it across the columns (Home → Merge & Center).
  10. Insert a new column after "Marks Obtained" titled "Result" — you'll fill this manually with Pass/Fail based on marks (this sets up for formulas in the next module).
  11. Save the file using Ctrl + S.

⚠️ Common mistakes to avoid during the exercise

Mistake: Applying currency/date formatting to the wrong column (e.g., formatting Roll No as currency). Always double-check you've selected the correct column before formatting.
Mistake: Not saving before closing — always save with Ctrl + S after each major step.

T8 · Test 1 + Doubt Session

📌 Purpose

Test 1 checks understanding of T1–T7: Excel interface, navigation, data entry, formatting, and number formats. The doubt session lets students clarify anything unclear before moving to Module 2.

📝 Likely test areas (based on T1–T7)

  • Identifying parts of the Excel interface (Ribbon, Formula Bar, Name Box, Sheet Tabs).
  • Writing correct cell addresses and ranges (e.g., what does B2:D6 mean?).
  • Steps to format a cell (bold, borders, fill color, wrap text).
  • Steps to insert/delete a row or column correctly.
  • Choosing the right number format for a given type of data (currency vs. date vs. percentage).

🛠️ How to prepare

  1. Re-open the practice file from T7 and redo the formatting steps without looking at instructions, to test recall.
  2. Practice navigating using Name Box and Ctrl+Home / Ctrl+End without the mouse.
  3. Note down any step you hesitate on — bring it to the doubt session.

⚠️ Common mistakes seen in tests

Mistake: Mixing up row vs. column terms, or writing cell address as "2B" instead of "B2" (column letter always comes first).

⚡ Quick Revision — Module 1

  • Workbook = whole file. Worksheet = one tab/page inside it. Cell = intersection of a row and column.
  • Cell address = Column letter + Row number (e.g., B3). Range = B2:D6.
  • Navigate fast: Name Box, Ctrl+Home (go to A1), Ctrl+End (last used cell).
  • Edit a cell: double-click or press F2. Save: Ctrl + S.
  • Formatting (Font, Alignment, Borders, Fill Color, Wrap Text) is all in the Home tab.
  • Resize rows/columns by dragging borders, or right-click → Row Height / Column Width for exact values.
  • Insert/Delete rows & columns via right-click on the row number / column letter.
  • Number formatting (Currency, Date, Time, %, Decimal) via Home tab dropdown or Ctrl + 1 → Format Cells.
  • Formatting changes only the display, never the actual stored value.
