T17 · Formula Basics (=, +, -, *, /)

📌 What is it?

A formula is an instruction that tells Excel to calculate something. Every formula in Excel must start with an equals sign (=) — this is what tells Excel "this is a calculation, not plain text."

🧩 Basic operators

OperatorMeaningExample
+Addition=A1+A2
-Subtraction=A1-A2
*Multiplication=A1*A2
/Division=A1/A2
^Power (exponent)=A1^2

🛠️ How to write a basic formula

  1. Click the cell where you want the result to appear.
  2. Type = to start the formula.
  3. Click the first cell you want to use (e.g., A2) instead of typing its value directly — Excel inserts the cell reference automatically.
  4. Type the operator (e.g., +).
  5. Click the second cell (e.g., A3).
  6. Press Enter to see the result.

⏰ When to use cell references instead of numbers

Always prefer =A2+A3 over typing =78+85 directly. If the values in A2 or A3 change later, a formula using cell references updates automatically — a formula using typed numbers does not.

⚠️ Common mistakes

Mistake: Forgetting the = sign — typing A1+A2 without it just becomes plain text, not a calculation.

T18 · Cell References (Relative, Absolute & Mixed)

📌 What is it?

Cell references decide what happens to a formula when you copy it to other cells. There are three types:

TypeWritten asBehavior when copied
RelativeA1Changes automatically based on new position
Absolute$A$1Never changes — stays locked to A1
Mixed$A1 or A$1Only column OR only row stays locked

🛠️ How to create an Absolute Reference

  1. Click into the formula, right after the cell reference you want to lock (e.g., click right after "A1" in =A1*B2).
  2. Press F4 — Excel automatically adds dollar signs: $A$1.
  3. Press F4 again to cycle through Mixed reference options: A$1 → $A1 → back to A1.

🌍 Real-world example

GST calculation: If GST rate 18% is fixed in cell B1, and you want to calculate GST for many products in column A, your formula should be =A2*$B$1. When you copy this formula down to A3, A4, etc., the price reference (A2) changes to A3, A4 — but the GST rate reference stays locked to B1 because of the dollar signs.

⏰ When to use each type

  • Relative — default choice, use when each row needs its own calculation based on its own row's data.
  • Absolute — use when one fixed cell (like a tax rate, a fixed bonus, or a conversion rate) is used across all rows.
  • Mixed — used in more advanced tables, e.g. multiplication tables where only the row or only the column should stay fixed.

⚠️ Common mistakes

Mistake: Forgetting to lock a fixed-value cell (like a tax rate) with $ signs — when the formula is copied down, the reference shifts to a blank cell and the formula breaks or gives 0/error.

T19 · SUM(), AutoSum(), AVERAGE()

📌 What is it?

These are built-in functions — ready-made formulas for common calculations, so you don't have to write out long addition manually.

🧩 Function basics

FunctionPurposeExample
SUM()Adds up all values in a range=SUM(C2:G2)
AVERAGE()Calculates the mean (average) of a range=AVERAGE(C2:G2)

🛠️ How to use SUM() manually

  1. Click the cell where the total should appear.
  2. Type =SUM(
  3. Select the range of cells to add (e.g., click C2 and drag to G2).
  4. Type ) to close the bracket.
  5. Press Enter.

🛠️ How to use AutoSum (fastest way)

  1. Click the empty cell right after (or below) the numbers you want to add.
  2. Go to Home tab → AutoSum (the Σ symbol), or press Alt + =.
  3. Excel automatically guesses the range — check it's correct, adjust by dragging if needed.
  4. Press Enter.

🛠️ How to use AVERAGE()

  1. Click the destination cell.
  2. Type =AVERAGE( then select the range → close bracket ) → press Enter.
  3. Shortcut: click the small dropdown arrow next to AutoSum (Σ) → choose Average.

⚠️ Common mistakes

Mistake: Including the "Total" column itself inside a SUM range by accident — always double-check the selected range doesn't loop back on its own result.

T20 · MIN(), MAX(), COUNT(), COUNTA(), COUNTBLANK()

📌 What is it?

More built-in functions for quickly analyzing a range of data — finding smallest/largest values, or counting cells.

🧩 Function reference

FunctionPurposeExample
MIN()Finds the smallest number in a range=MIN(C2:C16)
MAX()Finds the largest number in a range=MAX(C2:C16)
COUNT()Counts cells containing numbers only=COUNT(C2:C16)
COUNTA()Counts all non-empty cells (numbers + text)=COUNTA(B2:B16)
COUNTBLANK()Counts empty cells in a range=COUNTBLANK(H2:H16)

🛠️ How to use these functions

  1. Click the destination cell.
  2. Type = followed by the function name, e.g. MAX(
  3. Select the range of cells.
  4. Close the bracket ) and press Enter.

🌍 Real-world example

On a marksheet: =MAX(C2:C16) finds the topper's Maths score, =MIN(C2:C16) finds the lowest score, =COUNTBLANK(H2:H16) tells you how many students still don't have a Grade filled in.

⏰ When to use COUNT vs COUNTA vs COUNTBLANK

Use COUNT to count how many students have a numeric score entered. Use COUNTA to count how many cells have any entry at all (like names, which are text). Use COUNTBLANK to check how many entries are still missing.

⚠️ Common mistakes

Mistake: Using COUNT() expecting it to count text cells too — it only counts numeric cells. Use COUNTA() for text or mixed data.

T21 · ROUND(), ROUNDUP(), ROUNDDOWN()

📌 What is it?

These functions control how many decimal places a number is rounded to.

🧩 Function reference

FunctionBehaviorExampleResult
ROUND()Rounds normally (0.5 and above rounds up)=ROUND(78.456, 1)78.5
ROUNDUP()Always rounds up, no matter the decimal=ROUNDUP(78.421, 1)78.5
ROUNDDOWN()Always rounds down, no matter the decimal=ROUNDDOWN(78.489, 1)78.4

🛠️ How to use ROUND()

  1. Click the destination cell.
  2. Type =ROUND(
  3. Click the cell with the number to round (e.g., the Percentage cell).
  4. Type a comma , then the number of decimal places you want (e.g., 2 for 2 decimal places, or 0 for a whole number).
  5. Close the bracket ) and press Enter.

ROUNDUP() and ROUNDDOWN() work exactly the same way — just swap the function name.

⏰ When to use this

Use ROUND() for displaying clean percentages/averages (e.g., 78.456% → 78.46%). Use ROUNDUP() in situations like billing, where you always want to round in the business's favor (e.g., rounding up total cost). Use ROUNDDOWN() when you must not overstate a number, e.g. rounding down available stock quantity.

⚠️ Common mistakes

Mistake: Confusing ROUND() with just changing decimal display (Format Cells → decrease decimal). Format Cells only changes how it looks; the actual stored value stays unrounded. ROUND() actually changes the stored value.

T22 · Percentage & GST Calculations

📌 What is it?

Common real-world formulas: calculating a percentage of a number, and calculating GST (Goods and Services Tax) added to a price.

🧩 Key formulas

GoalFormula
Percentage of marks=(Total/Max Marks)*100
GST Amount=Price*(GST_Rate/100)
Final Price (with GST)=Price+GST_Amount or =Price*(1+GST_Rate/100)

🛠️ How to calculate Percentage (marksheet example)

  1. Click the "Percentage" cell for a student.
  2. Type =( then click the Total marks cell.
  3. Type / then type the maximum possible total (e.g., 500 if there are 5 subjects out of 100 each).
  4. Close the bracket, then type *100
  5. Press Enter. Example: =(H2/500)*100

🛠️ How to calculate GST Amount

  1. Click the "GST Amount" cell.
  2. Type = then click the Price cell.
  3. Type * then click the GST Rate cell.
  4. Type /100 (since GST rate is stored as a plain number like 18, not 0.18).
  5. Press Enter. Example: =B2*C2/100

🛠️ How to calculate Final Price (with GST)

  1. Click the "Final Price" cell.
  2. Type = then click the Price cell.
  3. Type + then click the GST Amount cell.
  4. Press Enter. Example: =B2+D2

⏰ When to use this

Percentage formulas apply to marksheets, discounts, growth rates, and pass ratios. GST formulas apply to any billing/invoice sheet with tax calculation.

⚠️ Common mistakes

Mistake: Forgetting to divide the GST rate by 100 — typing =B2*C2 when C2 holds "18" gives a hugely wrong number instead of 18% of the price.

T23 · Practical Exercise — Student Marksheet

📌 Goal

Apply everything from T17–T22 on a real marksheet: SUM, AVERAGE, MIN/MAX, ROUND, and Percentage formulas — plus a separate GST practice sheet.

Dataset provided: Student_Marksheet_Dataset.xlsx — two sheets:
Sheet "Marksheet": 15 students with marks in Maths, Science, English, Computer, Social Science (out of 100 each). Total, Average, Percentage, and Grade columns are left blank for you to calculate.
Sheet "GST Calculation": 8 products with Price and GST Rate given; GST Amount and Final Price columns left blank.

🛠️ Step-by-step exercise instructions

  1. Open Student_Marksheet_Dataset.xlsx → go to the Marksheet sheet.
  2. Total column (H): Click H2 → use AutoSum (Alt + =) to sum C2:G2. Drag the Fill Handle down to H16.
  3. Average column (I): Click I2 → type =AVERAGE(C2:G2) → Enter. Fill down to I16.
  4. Percentage column (J): Click J2 → type =(H2/500)*100 → Enter. Fill down to J16.
  5. Round the Percentage: Wrap it with ROUND: =ROUND((H2/500)*100,2) for 2 decimal places.
  6. Grade column (K): For now, manually type a grade based on percentage (A/B/C/D) — you'll learn to automate this with IF() in the next module.
  7. Class stats: In empty cells below the table, calculate:
    • Highest Total: =MAX(H2:H16)
    • Lowest Total: =MIN(H2:H16)
    • Number of students: =COUNT(H2:H16)
    • Students with missing Grade: =COUNTBLANK(K2:K16)
  8. Switch to the GST Calculation sheet.
  9. GST Amount (D): Click D2 → type =B2*C2/100 → Enter → fill down to D9.
  10. Final Price (E): Click E2 → type =B2+D2 → Enter → fill down to E9.
  11. Format the Price, GST Amount, and Final Price columns as Currency (from Module 1, T6).
  12. Save the file using Ctrl + S.

⚠️ Common mistakes to avoid during the exercise

Mistake: Using absolute reference on the wrong cell — in this exercise, the max marks (500) and GST rate columns need care about whether they're a single fixed cell or a per-row value. Since GST Rate here is a per-row column (C2, C3...), don't lock it with $ signs — that's only needed if a single tax rate cell is reused for every row.
Mistake: Dragging the Fill Handle without checking the last row — make sure formulas are filled exactly to row 16 (Marksheet) / row 9 (GST sheet), matching the data.

T24 · Test 3

📌 Purpose

Test 3 checks understanding of T17–T23: formula basics, cell references, core functions (SUM/AVERAGE/MIN/MAX/COUNT family), ROUND functions, and percentage/GST calculations.

📝 Likely test areas

  • Writing a basic formula correctly starting with =.
  • Difference between Relative ($ none), Absolute ($A$1), and Mixed ($A1 or A$1) references, and predicting what happens when a formula is copied.
  • Choosing the correct function: SUM vs AVERAGE vs COUNT vs COUNTA vs COUNTBLANK.
  • Difference between ROUND, ROUNDUP, and ROUNDDOWN outcomes for the same number.
  • Building a percentage formula and a GST formula from scratch.

🛠️ How to prepare

  1. Re-do the T23 marksheet exercise from scratch without instructions, timing yourself.
  2. Practice converting a formula's relative reference to absolute using F4 until it's automatic.
  3. Write out, on paper, what COUNT/COUNTA/COUNTBLANK would each return for a sample column with some numbers, some text, and some blanks — check your answers in Excel.

⚠️ Common mistakes seen in tests

Mistake: Forgetting that GST rate or tax percentages stored as whole numbers (like 18) must be divided by 100 in formulas — a very common calculation error.
Mistake: Mixing up when a $ sign locks the column vs the row in a mixed reference ($A1 locks column A; A$1 locks row 1).

⚡ Quick Revision — Module 3

  • Every formula starts with =. Basic operators: + - * / ^.
  • Relative (A1) changes when copied. Absolute ($A$1) never changes. Mixed ($A1 or A$1) locks only column or only row. Toggle with F4.
  • SUM() adds values; AutoSum (Alt + =) is the fast shortcut; AVERAGE() finds the mean.
  • MIN()/MAX() find smallest/largest. COUNT() = numeric cells only. COUNTA() = all non-empty cells. COUNTBLANK() = empty cells.
  • ROUND() rounds normally. ROUNDUP() always rounds up. ROUNDDOWN() always rounds down. All actually change the stored value (unlike Format Cells decimal display).
  • Percentage formula: =(Part/Total)*100. GST Amount: =Price*(Rate/100). Final Price: =Price+GST Amount.
  • Always double check whether a reference should be locked ($) — fixed single values (like one shared tax rate) need $, per-row values don't.
